## 三、同仓多包结构草案（身体库侧，待结构选型裁定后细化）

原文形态保留：宿主只留 core；`lingshu[full]` 一次装齐；旧路径薄壳再导出。本文件补三候选：

| 选项 | 形态 | 优点 | 代价 |
|---|---|---|---|
| A 扁平顶层包 | 仓根下 `world-verify/`、`world-sim/`… 各自独立 pyproject | 包边界最硬（目录即边界） | 全仓 `lingshu.world.x` import 面大改；薄壳层必须完整 |
| B `packages/` 命名空间 | `packages/world-verify/`… | 仓根整洁；多包意图显式 | 同 A 的 import 改面 |
| C `lingshu/` 内边界＋分发拆分 | 目录不动，pyproject 按 path 拆 wheel、import-lint 守边界 | **import 面零改动**、薄壳天然存在、守卫先行的渐进路径 | 边界靠守卫不靠目录（纪律依赖 lint 长期在位） |

**渐进推荐**（供裁定，非结论）：C 先行（守卫＋pyproject 拆分发），验证包间无交叉边守卫稳定运行一个大版本后，再评估是否升 A/B。理由：`lingshu.world.x` import 面遍布 tests/tools/docs（数百处），一次性改面违反「拆分 PR 不夹带」原则；C 可每包一个 PR 渐进落。
