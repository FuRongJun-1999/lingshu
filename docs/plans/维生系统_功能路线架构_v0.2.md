## 一、双面架构（v0.2 核心修订）

**维生系统不是一件事，是两个面，保证性质完全不同：**

| | **机械面** | **裁决面** |
|---|---|---|
| 本质 | 确定性状态机＋白名单反射 | 语义判决（智能论 3.4 第十二部分「维生系统裁决权」） |
| 参与者 | **零 LLM**——纯自动化程序 | **LLM 或维护者，以维生系统身份和责任**做出判决 |
| 可复算性 | 逐位可复现（守卫＋变异自证即可验收） | 不可机械复算——以身份归属＋证据状态＋留痕验收 |
| 判据形态 | 阈值/白名单/闭式条件（能写成 if 的） | 需要理解意思的（智能论 D_meta 侧） |
| 失败形态 | 漏判/误判皆可由守卫当场暴露 | 后验 1 ≠ 原因确认（#110 漏真反例）——须保留「未解释」容量与候选重开 |
| 审计 | action_logs＋status 流转 | 裁决身份（vital_system actor）＋证据链（候选/参数版本/动作/测量/传感器模型/预算） |

**面间边界（唯一判据）**：能写成闭式条件且后果有界的 → 机械面；需要「理解意思」或后果不可逆的 → 升裁决面。边界本身登记在案（分派表即边界声明），改动＝改分派表＝可审计。

**理论锚点（智能论 3.4）**：
- **2.3 三级仲裁**：仲裁不单独设实例，是维生系统的多级响应机制（对应 3.4 节保护协议）——本架构的三级映射：**L1 机械反射**（状态机自愈，零判断）→ **L2 维生裁决**（LLM 以维生系统身份做语义判决）→ **L3 设计者终裁**（价值/路线级，1.4.1 设计者结构性隔离不被打破——设计者只在终裁位，不承担维生操作职能）。
- **3.15 校准分级流程**＝裁决面的流程模板：验证单元识别 → 维生系统确认 → 执行 → 记录保存于记录单元。
- **第十二部分：维生系统裁决权**＋21.3 终裁 FINAL-v3.2：裁决权有授权固化形态，非临时授权。

## 三、双面架构总图

```
机械面（零 LLM，确定性，逐位可验）
 [信号源] → 感知探针 → check_escalation 阈值门 → ESC 码分派表
   ├─ 白名单反射（M-V3）：状态机自愈，action_logs 留痕
   ├─ 登记：designer_todos(status=open) ＋ 提醒队列
   └─ 闭式可判处置：直接执行（白名单内）或降级声明
            │ 超出闭式判据 / 语义模糊 / 后果不可逆
            ▼（升级 = 唯一跨面通道）
裁决面（智能论 3.4 维生系统裁决权）
 L2 维生裁决：LLM 以维生系统身份（actor=vital_system）做语义判决
   ├─ 输入：#110 证据状态机（observationally_compatible / response_supported / unresolved / contradicted）
   ├─ 输出：裁决＋理由＋证据链（候选/参数版本/动作/测量/传感器模型/预算）
   └─ 高危/价值级 → L3 设计者终裁（designer_decide，structural isolation 不破）
 回写：evidence_state ＋ action_logs ＋ R 类学习记忆
```

## 四、分阶段功能路线（按双面重排）

### M-V1：机械面消费循环（零 LLM，即 #130 主诉的直接闭合）

同 v0.1 M-V1，**明确其全部为机械面**：`consume_designer_todos` ＋ ESC 分派表（闭式判据子集）＋ status 流转＋白名单内直接处置。LLM 不参与——凡分派表写「只上报」的，一律登记后等待裁决面，机械面不越权。

**守卫/验收同 v0.1**（五守卫＋变异自证＋全链路演练）。

### M-V1.5：裁决面建立（新增，双面架构的另一半）

1. **vital_decide(todo_id, judgment, evidence_ref, actor='vital_system')**——裁决接口：LLM 以维生系统身份（system prompt ＝ 维生系统职责声明：维持设计者交托的存在方式、不自主生成目标、只判语义不判价值）对上报项做语义判决；判决＋理由＋证据引用写入 action_logs。
2. **责任链**：L2 裁决（vital_system）→ 可被 L3 设计者终裁覆盖（designer_decide）；L2 裁决错误由 L3 纠正并留痕，形成可审计的责任归属。
3. **LLM 形态**：优先复用宿主已有 LLM 通道（蜂群 L2 裁决 = exec.py 委托形态，hive 已实测）；维生系统身份声明独立于宿主人格。
4. **守卫**：裁决必须引证据状态（不许裸判）；裁决不修改记忆内容本体；L3 可覆盖 L2（留痕）。

**验收**：注入语义模糊待办 → L2 裁决含理由＋证据引用 → designer 可见并可覆盖；actor 归属审计可查。
