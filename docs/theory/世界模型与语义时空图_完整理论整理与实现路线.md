## 〇、总的命题（贯穿全篇）

> **智能 = 对自身的诚实扮演**（设计者立场·AEIS 私有）。
> **世界模型 = 智能体对『世界如何演化』的内部模拟器**——不是静态知识库，
> 而是能预测『接下来可能发生什么』的动态结构。
> **语义时空图 = 世界模型在物理时空的投影**——把条件候选锚定到 3D 位置+时间，
> 让预测有空间坐标支撑。

**知识即信息差减少。智能不是得到答案，而是不断缩小『问题与可执行知识之间信息差』的递归过程。**

## 一、理论根基（白箱四篇）

### 1.1 白箱智能（入门第一篇）
- **核心四态**（资格判断）：`ACCEPT`（条件满足执行）/ `REJECT`（冲突拒绝）/
  `DEFER`（不足延后）/ `BLINDSPOT`（盲区不强猜）
- **白箱不消灭 LLM**——LLM 提候选，白箱判条件是否成立
- 『不知道』不是失败，是对认知边界正确判断；REJECT=能力层面拒绝

### 1.2 信息差必然存在（论证篇·第二篇）
三体/混沌（确定性系统对初值敏感×观测者有限）、信道容量（香农 R>C 差错不可避免）、
1+1=2（知识须绑定操作语义）。**信息差永远存在、自然扩大**。

### 1.3 智能公理化（第三篇）
- **知识 = 条件空间 C 中的有效关系**：`K=K(C), D=D(C)`
- 条件空间四维度：观测位置 / 观测工具 / 时间窗口 / 存在约束

### 1.4 智能认知过程（第四篇）
识别条件→找适用知识→并行评估→执行→验证→发现误差→找遗漏条件→更新结构→再验证。

## 三、语义时空图理论

### 3.1 认知图 vs 语义时空图（设计者裁决）

| | 认知图（条件路由图）| 语义时空图 |
|---|---|---|
| **定位** | **操作系统** | **记忆系统** |
| 本质 | 条件路由总图（什么存在/如何路由）| 时间线+空间坐标（何时何地/如何演化）|
| 坐标 | 条件空间 | 时空坐标 |
| 一致性 | 同一概念在两底物投影一致（**投影-关联**）|

### 3.2 2D↔3D 对齐（映射问题，非猜测）
- 三视图（3视角）/ 双目视差（2视角，Z=f·B/d）/ 单目+先验（1视角·近似）
- 语义对齐走**投影-关联**（已知相机参数→3D锚点投影回2D验证），非特征融合

### 3.3 五个待验证问题裁决
1. 2D↔3D=映射（投影-关联）；2. 3D锚点可信度=多模态交叉+物理一致+时间一致；
   3. 4D采样率=30帧/s；4. 认知图=OS/语义时空图=记忆系统；5. T_h=认知根本局限（信息差无法消除）

## 四、图像认知实现（L1 感知层的具体展开）

> 过去几轮把感知层从『边缘/背景差』升级为『语义+颜色分层+骨架+连通域』——
> 更贴合『识别靠线结构/颜色分层』（设计者方法论）与白箱原则。

### 4.1 感知管线（从图像到语义）

| 环节 | 模块 | 方法 |
|---|---|---|
| 去背景 | cc_segment | 连通域均值化（相近色块合并，背景/人物分离）|
| 人物提取 | skeleton_fit.cc_person_mask | 肤色先验（人物肤色区，排除非肤色背景）|
| 骨架拟合 | skeleton_fit | 人物轮廓→离散点中心线→骨架（逐列中心）|
| 骨架匹配 | stickman_match.match_skeleton_person_mask | 骨架关节匹配人物掩码，cov 0.82-0.94 |
| 部位定位 | skeleton_fit / leg_detect | 腿关节映射→区域间隙→目标部位 ROI |
| 语义识别 | condition_route.route_semantics | 条件路由四态（ACCEPT/REJECT/DEFER/BLINDSPOT）|
| 子部位mask | condition_route.subject_to_subpart_mask | 判定部位→像素mask（可细分/语义连接）|
| 特征模板 | feature_template | 区域轮廓曲线（Kasa 圆拟合）标准化模板 |
| 上色/编辑 | semantics.recolor_regions | 语义区域→mask精确上色→生成（改色=改语义）|

### 4.2 测试（对应模块均 ALL PASS）
test_cc_segment / test_skeleton_fit / test_match_skeleton_person_mask /
test_roi_recognition / test_pose_route / test_scene_card /
test_feature_template / test_condition_animation 等。

### 4.3 图像认知闭环

```
图像 → 连通域去背景 → 肤色先验(人物) → 骨架匹配(腿关节,cov高)
  → 目标部位 ROI → 条件路由四态 → 子部位 mask → 特征模板/语义连接
```

## 五、完整实现路线（从理论到系统）

### 阶段 A：感知层（L1）已实现
图像认知管线（4.1 节）——从图像到语义/部位/mask/模板，零LLM确定性。

- 部位与已学语义建边（contains / part-of / 条件）
- 复用 world3d / st_graph / semantic_anchor_graph

### 阶段 C：理解层（L3）——条件路由（已实现）+ 语义连接
- route_semantics 四态判定（ACCEPT/REJECT/DEFER/BLINDSPOT）
- 子部位mask ↔ 已学语义节点绑定

### 阶段 D：预测与验证（L4/L5）
- predict_routes（候选未来）基于时空图
- anchored_verification（锚点验证）

### 阶段 E：多模态统一（设计者方向）
- 视觉（VPrim）+ 听觉（APrim）+ 触觉（TPrim）→ 多模态交叉提升锚点可信度
- 自我参考（selfref/self_expression/self_conscious）→ 共情=自我模拟

### 阶段 F：完整世界模型闭环
- seven_layer_loop 整合感知→记忆→理解→预测→验证→决策
- game_web 交互式世界游戏（实时可见七层闭环）

## 六、关键原则（贯穿实现）

1. **白箱**：每步可溯源（条件显式、零LLM确定性 D-005）
2. **投影-关联**：语义对齐走投影回2D验证，非黑箱特征融合
3. **颜色分层+线结构**：识别平滑区域靠颜色分层+骨架，非边缘
4. **条件空间**：任何知识/识别须绑定条件（观测位置/工具/时间/存在约束）
5. **自我模拟**：共情/理解他人=摆自我姿态→自我感受，非黑箱猜
