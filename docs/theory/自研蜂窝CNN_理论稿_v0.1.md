> 荣 2026-09-06 架构裁定：**自研 CNN + 并行条件路由神经网络是传感器层唯一需要的原生架构**；
> 视觉使用蜂窝形感知；同一架构复用于语音/图像/视频/文字多模态学习。
> 代码：`aeis/hex_cnn.py` ｜ 测试：`tests/test_hex_cnn.py`（25/25）｜ 可视化：`data/vision/hex_cnn_m1/`

## 一、四条裁定（grill 访谈 2026-09-06）

1. **CNN×条件路由一体**：CNN 是条件路由的特征前端（蜂窝晶格→特征图），
   路由是 CNN 的语义判定层（条件卡→滤波器组→四态）——一个架构，不是两层拼装。
2. **自监督+白箱固化**：核参数可学习（掩码重建目标，数值梯度全程可审计），
   学完固化即白箱（`kernels_img0.json`——JSON 可直读，加载即确定性模块）。
   理论依据：《世界模型理论_白箱固化_v1》——引导建白箱，固化后零训练。
3. **统一蜂窝晶格+共享底座**：各模态前端编码为统一蜂窝晶格表示
   （图像块/语音谱帧/视频时空块/文字段），共享 HexConv 底座+并行条件路由。
4. **视觉先行**：M1 用 img0/示范图验证，对接既有子部件/条件卡管线。

## 二、蜂窝形感知的实现依据（白箱身体补充计划 §六 落地）

| 性质 | 实现 |
|------|------|
| 6 邻等距（各向同性） | `HexGrid.neighbors` 6 方向等距（测试：spread=3e-15）——方阵 3x3 对角 √2 不均的根治 |
| 最优镶嵌（honeycomb） | 错行矩形存储（axial 坐标，pointy-top），像素↔cell 往返（axial round） |
| 生物视网膜六角 | `kernel_center_surround`（中心-周围拮抗感受野，常数场零响应） |
| HexConv 6邻 stencil | 7 参数核 [自身+E/NE/NW/W/SW/SE]，奇偶行偏移表混合；边界 replicate |
| 手写可解释核先例 | smooth（7 点均匀，蜂窝独有各向同性平滑）/ Laplacian（邻均值−自身） / 方向边缘 |

## 三、并行条件路由 NN 层

- `ConditionFilterCard`：条件卡谓词参数化为「核+通道+响应阈值」——
  响应=|HexConv 特征|，四态判定与 `condition_route` 语义一致：
  **ACCEPT**(≥阈值)/ **DEFER**(≥0.5×,证据弱待验)/ **REJECT**(≤0.1×,条件冲突)/ **BLINDSPOT**(不可判带)。
- `parallel_route`：全部卡并行评估同一特征图（无状态依赖，每卡独立证据报告）。
- 证据链：reason（响应/阈值数值）+ response + ratio——白箱可审计。

## 七、文字模态设计(2026-09-06 荣定方向:不走 ViT token 化路线)

> 荣:常见的 ViT 是把文字切 token、图片切 patch,统一序列做 transform 学习。
> 我们走的是**语义还原、条件切换、子部件嵌套**——不是这条路。

### 7.1 两条路线的本质分野

| | ViT/token 路线 | 我们的路线 |
|---|---|---|
| 第一步 | 切 token/patch——**丢弃结构** | 结构显式保留(嵌套+条件),从不丢弃 |
| 结构来源 | attention 从海量数据**统计地猜回来** | 显式给定(条件卡/嵌套 subgraph),CNN 只提供特征证据 |
| 语义 | embedding 向量(黑箱空间位置) | 条件满足的还原(哪些部件条件成立→组合出什么语义) |
| 多模态对齐 | CLIP 类黑箱对比学习 | 同构表示天然同库(图文语义同一认知图) |
| 数据需求 | 饥渴(要猜回结构) | 小数据(结构是先验,证据只需确认) |
| 可审计性 | 权重黑箱 | 每卡四态+响应证据 |

### 7.2 汉字 = 子部件嵌套的原生数据(六书)

- 象形:图形直接映射;会意:部件组合出义(人+木=休);
- **形声:形旁表义+声旁表音 = 条件组合卡**(氵+古=湖)——汉字几千年前已把语义做成子部件嵌套。
- 嵌套同构:图像 person→head→eyes ↔ 文字 笔画→部件→字→词——同一结构,不同字典。

### 7.3 文字管线(与图像完全同构)

```
字形渲染→蜂窝晶格(汉字方块天然二维,最适合蜂窝采样)
→ HexConv 方向核族提笔画证据(横/竖已有,斜向核 M2 补)
→ 部件条件卡并行路由(氵卡:左纵三点水结构,响应≥阈值→ACCEPT)
→ 字级条件卡(形声组合:形旁∧声旁)
→ 语义还原入认知图(与图像语义同库/同 subgraph 嵌套/同条件空间)
```

- **语义还原**=部件条件满足的组合还原(湖=水域条件+声旁条件),产出认知图节点,与图像语义可互链。
- **条件切换**=一字多义=同一字形卡在不同条件空间激活不同语义卡;语境证据不足=DEFER 不强行消歧。
- **子部件嵌套**=部件→字→词用认知图 subgraph+part_of 边,每层独立条件卡独立四态。

### 7.4 M4 文字模态的新增量(架构零新增)

方向核族/条件卡引擎/嵌套认知图全部复用;新增仅:
1. 字形→晶格渲染编码器(字体渲染→蜂窝采样,复用 image_to_grid);
2. 部件条件卡字典(~200 部首级卡:位置条件+结构谓词→滤波器参数);
3. 验证实验:手写"休"字上晶格→人形旁卡+木旁卡并行 ACCEPT,响应图显示左右结构——
   同时验证模态无关性与形声结构可计算性。

## 八、正交性约束 + 信息差自适应深度（显式化 2026-09-10）

> 来源：`agi-architectures/外部AGI架构_对照深化` ACCEPT 项 #3（VCP-ToolBox ResidualPyramid：
> 语义方向 Gram-Schmidt 正交化 + 残差能量占比低于 minEnergyRatio(0.1) 即停）。
> 本仓同构理论早已在册（《子部件提取_理论稿_v0.4》§〇.A.4/A.5 残差=信息差→自适应阈值→死区停；
> §六 深度上限=可分性条件自然耗尽），但**只有理论没有接口**：
> `recursive_search` 的 `min_share` 声明了却从未生效，`found` 又把盲区证据过滤掉。
> 本节把这两处显式化为可调用、可审计、可回归的接口。

### 8.1 同构关系（白箱版，不引入黑箱 embedding）

| VCP ResidualPyramid | 本节（白箱版） |
|---|---|
| 在**向量空间**对语义方向 Gram-Schmidt 正交化（方向来自模型，黑箱） | 在**特征(晶格)空间**对**核算子**正交匹配（方向=手写核，白箱） |
| 残差能量占比 < minEnergyRatio(0.1) 停 | 残差能量占比 < `dead_zone`(默认 0.10) 停 |
| 输出「语义能量谱 + 最终残差」 | 输出 `energy_spectrum` + `residual_share` + 逐层证据 |

数学同一：原子 `a_c = P_c F₀`（核 c 在原始特征上的 HexConv 响应），
残差 `r_k = F₀ − Σ_j β_j a_j`，β 由最小二乘对**全部**已选方向重解
→ `⟨r_k, a_j⟩ = 0 ∀j`。这就是「子部件不重复解释」的可测量定义。
能量守恒：`‖F₀‖² = ‖r_k‖² + ‖Σβ_j a_j‖²`，故 `cumulative_share = 1 − residual_share²`。

### 8.2 增量① 正交性约束（`gram_schmidt_kernels` / `orthogonal_pool`）

逐核算「新信息占比」`‖k − Σ已保留 proj‖ / ‖k‖`，低于 `tol`(0.20) 判为重复解释并从候选池剔除。
实测核族 `extended_prior_family(12)`：**剔除 7 个**（`edge_d3/4/5` 与 `edge_d0/1/2` 同轴取反、
`coarse≈smooth`、`center_surround = −laplacian`、两个 noise 变体），正交池 5 个
——同一份语义能量此前被两遍计入能量谱。

### 8.3 增量② 信息差自适应深度（`residual_pyramid`）

层数由数据决定，不预设：

```
逐层: 选 |⟨r,a_c⟩|/‖a_c‖ 最大的核 → 全体已选方向最小二乘重解 → 更新残差
停止(自适应,顺序判定): card_exhausted / orthogonal_exhausted / dead_zone / max_layers
```

`max_layers`(8) 降级为**工程保险上界**（防病态输入打爆算力），不再是语义深度；
停因 `stop_reason` 全程可查。实测默认配置下 `depth=2 < max_layers=8`（自然停止），
死区调大层数单调减（`dead_zone=0.9 → depth=1`，停因 `dead_zone`）。

搜索侧同构落地：`recursive_search(..., adaptive_depth=True, min_share=0.5)`
——`min_share` 生效为「子域占父域能量占比」死区（信息差入死区即不再下钻），
`max_depth` 同步降级为工程上界；停因与份额证据入
`stats["stopped_dead_zone"]` / `["stopped_max_depth"]` / `["blindspot_evidence"]`
（后者此前被去重逻辑吞掉，外部不可见——诚实终止的证据现在外传）。

### 8.4 验证（`python -m pytest tests/test_hex_ortho.py tests/test_hex_search.py`）

```
18 passed（hex_ortho 11 + hex_search 7）
正交性硬证据 : 残差对全部已解释方向的重叠 ≤1e-4（界仅由 float32 卷积数值误差决定）
能量守恒     : cumulative + residual² = 1（误差 <1e-3）
自适应深度   : dead_zone↑ → depth↓（非增）；默认 depth<max_layers；死区停计数与证据一致

```

### 8.5 边界声明（诚实）

- **默认关闭**：`adaptive_depth=False`、正交池为 `residual_pyramid` 内部默认；
  切换默认值需先校准 `min_share`（本次未做，属实验议题）；
- **死区过激伤召回**：测试用 `min_share=0.5` 只为触发机制，不应作为生产值；
- **正交性是线性（算子）意义**：覆盖「解释能量不重叠」；
  同一像素被多卡以**非加性**方式纠缠解释不在覆盖内；
- **核族去重是输入无关的**：用核向量线性相关判定；
  「不同核在特定输入上响应恰好相同」需按输入做 Gram-Schmidt（未实现，列为后续）；
- 正交池「剔除」判据 `tol=0.20` 为工程初值，未做敏感性实验。
