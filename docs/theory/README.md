## 引用链（三柱如何咬合）

```
世界模型理论（白箱固化：引导→固化→零 LLM）
   └─ 是 ── 自研蜂窝 CNN 的理论依据
存算一体架构（认知图 = 存算一体：节点既是存储又是计算单元）

   └─ 是 ── 世界模型在感知/特征域的实现件（传感器之后的第一段）
```

三条主链一句话：**反传语义**（信息差递归分配 + 死区门控）替代反向传播；**白箱原则**（全程可审计、每步可复算）零容忍黑箱；**四态资格裁决**（ACCEPT / REJECT / DEFER / BLINDSPOT）贯穿节点、路由与搜索剪枝。
