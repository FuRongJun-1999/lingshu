# 二值掩码连通域几何 v0.1

`analyze_binary_components(mask, ...)` 只分析调用方已经给定的布尔二维掩码。它把相邻前景像素归成连通域，并给出有限数量的面积、半开 bbox 和像素中心质心摘要。它不从 RGB 推断前景、不识别物体、不填孔洞、不读文件、不调用模型、不写文件/记忆。

## 输入与资源界限

- 输入为非空矩形的 Python `list`/`tuple` 二维结构；每格严格 `bool`，不把整数 0/1 偷换为布尔值。
- 4 或 8 邻接由 `connectivity` 明确指定；默认 4。掩码中的 False 是背景，算法不猜颜色阈值。
- 最大 262,144 像素。外层/行类型、宽高、矩形性先校验；超预算在创建 visited/queue 工作区前拒绝。超过上限的输入不会静默缩放或下采样。
- `min_area` 最小为 1，面积小于它的区域从汇总组件列表中滤除；前景像素总数仍计入全部 True 像素。
- `max_components` 为 1..128。全图仍完整扫描；仅报告面积最大的前 N 个摘要，同时返回 `omitted_component_count`，它不会限制扫描工作量。

## 输出几何口径

- bbox 为 `[left, top, right, bottom]` 半开像素边界：左/上包括，右/下不包括。
- 质心使用每个像素中心 `(x+0.5, y+0.5)` 的算术平均。
- `touches_boundary` 表示该区域至少含一个最外圈像素。
- 先按面积降序，再按 top 和 left 升序稳定排序；等面积时由位置决定先后。
- 只返回 JSON-safe 几何标量与最多 128 个组件记录，不返回标签图、前景坐标或中间队列。

## 解释边界

连通域是掩码拓扑分组，不等价于现实物体身份：接触的物体会合并，断开的同一物体会拆分。调用方负责阈值化与掩码来源；此函数只计算明确输入的 bool 前景区域。
