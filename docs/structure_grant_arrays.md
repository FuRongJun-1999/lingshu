# 写服务的授权名单格式

`load_service()` 启动时检查每个 grant 的 `capabilities` 和 `instances`。
两者只接受由非空字符串组成的 JSON 数组。字符串、对象、null、嵌套数组、空项均报 `WriteError`，发生在 TLS 上下文与数据库初始化之前。
`instances` 可省略，表示没有实例执行上报授权；重复项折叠，名称精确匹配，不自动修剪或拆字。

配置由服务部署者维护，worker 无权修改。此检查避免误配置扩大或改变授权集合，不替代 mTLS、证书角色分离或操作系统账户隔离。
业务参数类型、游标口径属于既有 #1107 的其他面，不在本项改动内。
