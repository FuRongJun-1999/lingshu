# 世界模型观测契约与追逐预测修复

本次修改沿用公开实现的实体关系图、位置观测、轨迹统计、手写运动规则和外部验证闭环。目标是修正稀疏观测及评分的失真，并改善有可靠方向证据的追逐中心。没有新增依赖、神经网络训练、滤波器或物理引擎。

## 两轮修改与上游整合

第一轮以 `abb52d005fe6300b3e9b5fd022a5a64d33096693` 为基线；第二轮接着调查全观测追逐的轻微退化。提交前，上游发布 `c22385cb2d75f36bc12fd1de4449edbf92be8698`，已经修复部分同类问题。测量候选整合该版本，再次运行相同 bench；不能将上游已有的一对一身份关联、真实观测历史、异常反馈等修复算成本 PR 的新增贡献。推送期间上游继续发布 `777e18f` 的 core/导出修复，最终提交也整合该批次，并补跑相关回归；本文数字的比较基线仍明确为 `c22385c`。

第一轮剩余改动：

- 共享 `motion.py` 按真实观测的时间差估计速度。缺失观测不等于静止；没有样本时保留旧参数。节点保留最后实测位置，只在临时 shadow 中外推陈旧状态，并增加随观测年龄增长的启发式范围。
- 当前推断关系可以替换旧关系，`relation_history` 留存变更；没有足够联合观测时保留候选。真实观测的持续静止可移除旧关系。SimulationLoop 的假设节点与边保留原生命周期。
- 固定阈值的点命中与模型自报范围覆盖分开；learner、naive、oracle 使用同一点阈值，oracle gap 只比较同实体同刻的交集。无样本率与损失返回 `None`。
- 预测携带 `target_tick`。只有对应时刻的真实观测能验证或强化预测；探索顺序为选择→预测→世界推进→观测→比较→学习。
- AnchorVerification 读取不产生新稳定证据；可选 `observation_tick` 合并同刻提交，`evidence_id` 去重同通道证据及注册表更新。保留上游 `MIN_CHANNELS`、`STABLE_MIN_INTERVAL`、反证扣分与 fail-closed 判据。未提供 ID 时不能识别上游重复发送。
- `masked_loss` 按三次真实观测的时间间隔重建最后一点，只支持 `mask_last=1`；下一状态损失只评分新观测。这些是诊断，损失不做梯度更新。

第二轮追逐修改：

原实现中 `chase_stochastic` 将追逐者中心留在原位置。目标随机不意味着追逐者不动：源实体若持续朝目标运动，仍可以外推追逐中心，同时保留随机目标的宽范围。

推进中心要求自身方向持续性达到已有 `entropy_threshold=0.7`，且关系方向余弦代理不低于自身持续性。弱 seek 保留当前位置中心及现有可达范围。两条模型路径使用相同规则，好奇调度的弱 seek 范围与预测保持一致。这是显式启发式资格比较，不是统计检验或因果证明；没有新增拟合阈值，也没有读取实体的模拟器行为、目标配置或 RNG。

原始轻微退化为 `0.2394488744 → 0.2397603646`，约 0.13%。1,600 次预测中只有 8 次变化：短窗口将随机 player 偶然朝静止实体运动误判为 seek；第一轮正确排除“静止目标=随机目标”后，错误关系开始驱动定向中心，并影响后续 wolf/rabbit 的顺序预测。仅恢复原静止分类的消融在 10 个种子上恢复原读数；最终保留分类修复、限制弱关系对中心的作用。

整合额外保留上游多步预测接口与最近方向的限窗查询。长遮挡时从此前真实运动统计缓存取方向，仅用于临时外推；不将缓存写回为新观测。新增测试覆盖长遮挡及多步预测的目标时刻验证。多步中心按原规则迭代，范围仍是启发式，没有多步概率覆盖保证。

## 兼容性、验证与来源

调用方迁移示例、旧字段对应和无样本处理见 [指标 v2 迁移](world_model_metrics_migration.md)。`learning_curve`、策略比较也登记版本及实际评分阈值，避免仅转发变化后的率而丢失口径标记。

- `eval_phase` / `probe` 返回 `metric_version=2`；`learned_rate` 改为固定阈值点命中，旧范围口径见 `bound_coverage`。Unified/Seven 的 `hit_rate` 仍保留范围覆盖含义，并增加 `point_hit_rate`。无样本 `None` 是公开返回值变更。
- `verify_anchor` 的重复读取不再增加轮次；独立新提交仍须满足上游的时间间隔和通道门槛。`masked_loss(mask_last!=1)` 显式报错。上游 `predict` / `generate` 多步接口保留。
- 原基线快档 352 passed；第一轮 376 passed；第二轮 381 passed，均另有 73 subtests passed。Python 3.13.13，排除 `test_hex_search.py` 与 `test_hex_hier.py` 两个重件；测试时间不作为速度收益证据。
