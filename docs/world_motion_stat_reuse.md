# 观测窗口运动估计复用

`ObservationWindow` 是一次 learn/infer_patterns 的局部视图。使用同一视图期间，调用方须保持输入历史稳定。

- `_motion_estimate(eid)` 按实体保存一次真实上下文回填和 `_estimate_detail` 的结果，包括 None。
- `motion(eid)` 返回原有四元组或 None，单独调用时不构造公开诊断字典。
- `motion_detail(eid)` 复用同一原始估计，保留既有字段、真实 dt、长间隔降权及无效算术诊断。
- 四元组缓存与公开可变诊断字典分开；改写公开的 estimate 字段不改变 motion 的结果。
- 缓存仅属当前视图；新建窗口必须重新读取新观测，不跨 tick、不跨实体或实例共享。

本件不改变数值公式、阈值、关系推断、预测算法、记忆写入与导出清单。新增临时缓存保存已请求实体的上下文与原始估计，生命周期随视图结束；额外空间与已请求实体的窗口/回填点数同阶，内存峰值未实测。

性能收益依赖输入。稀疏或长期遮挡时可消除重复历史回查；密集场景的其他预测开销仍在。
复跑与所有原始计时见 [验收报告](testing/world-motion-stat-reuse-20261028.md)。
