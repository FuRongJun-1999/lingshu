# 本地图像像素统计 v0.1

`analyze_image_pixels(image)` 接受**调用方已解码**的 Pillow `Image.Image`，以固定且可复现的量化指标总结单张图片。解码（打开文件、读取流）是调用方的前置条件：本函数不自行打开文件、不调用解码入口，也不校验解码安全性（不是解码沙箱），只检查 `Image` 类型与尺寸，不强制调用方预先 `load()`；若传入尚未加载的文件图对象，Pillow 的转换会读取它已打开的流。它不调用视觉模型、不访问网络、不保存图像，也不写入身体记忆。

## 统计口径

- 统计原图尺寸，不做缩放；`width`、`height`、`pixel_count` 和输入 `source_mode` 均在结果中报告。
- 像素数硬上限为 4,194,304。超限在 Pillow 转换/像素复制前拒绝；无隐式降采样。
- 可见颜色先转为 RGBA，再把 alpha 合成到不透明白底；R/G/B 统计该可见结果。每通道返回 16 桶直方图：桶 `v // 16`，因此最后一桶覆盖 240–255；每个通道计数和等于 `pixel_count`。
- 亮度使用合成后的 RGB 依 Pillow `convert("L")` 的 8-bit 编码空间转换口径，报告 min/max/mean/stddev 及同样的 16 桶直方图。结果是编码样本统计，不解释为线性光能量。
- alpha 摘要描述源图转换到 RGBA 后的 alpha：min/max/mean，以及完全透明、部分透明、不透明像素数。没有显式 alpha 通道不等于一律不透明：调色板 `P` 模式可经 `Image.info["transparency"]` 携带透明索引或逐索引 alpha，Pillow 的转换会据此产生非 255 的 alpha；只有转换后 alpha 全为 255 的模式才报告全部不透明。
- 不额外应用输入附带的 ICC profile 或 gamma 校正；源模式到 RGBA 的转换保留 Pillow 的默认规则——该默认转换可能使用 Pillow 自带的内建 profile（例如 LAB 相关转换），因此不应读作「绝对不含色彩管理」。
- 输出是内容派生统计：固定结构、聚合计数与最多 64 个直方图整数；这些统计值由图像内容决定，不能承诺与图像内容无关。具体承诺是：不返回原始像素数组、图像路径、Pillow 对象或输入附带的元数据（如 `icc_profile`、`filename`、`info` 内容）。

## 依赖与验证

Pillow 是可选依赖，仅调用统计函数时导入；只导入 `lingshu.vision` 不需要 Pillow 或 NumPy。调用时若 Pillow 未安装会明确报错。回归使用内存构造的纯色、色块、灰度与带透明度图片检查计数和均值，并覆盖尺寸预算、坏输入、JSON 序列化及轻量导入。
